## Gate B blockers

1. The mounted drill has not completed the real RFC-0009 `lost` transition.
   RFC-0009 requires 24 hours without heartbeat; the Hub's production
   semantics and maintenance cadence were not shortened, and no clock was
   advanced or faked.
2. Because the run stopped before `lost`, reconnect, delete/denial, reenroll,
   and final B-isolation checks, those required mounted results are absent.
3. The available browser backend does not trust the explicit self-signed
   certificate. Requests made by curl/Node with verification disabled are not
   browser UI evidence. A browser-trusted certificate setup is required
   without disabling certificate validation.
