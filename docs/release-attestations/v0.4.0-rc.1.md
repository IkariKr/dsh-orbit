## 6. Scope and limitations

- Reverse-connected nodes, NAT traversal, reverse tunnels, fleet execution, new `terminal.pty`, and new `agents.run` are not part of v0.4 and remain v0.5 scope.
- Browser management authority, Selector apex authority, deterministic Node route authority, and private machine authority remain separate namespaces.
- Hub listens on loopback `127.0.0.1:5445`; private machine ingress terminates verified HTTPS on `registry-hub:5446` and forwards only over loopback HTTP inside the shared Hub namespace.
- Node failure fails closed; there is no silent failover.
- Routing requires wildcard DNS, wildcard TLS, an authenticated outer gateway, preserved canonical `Host`, and active five-condition eligibility.
- RouteIngress nonce replay state is process-local; the signed proof, 30-second timestamp skew window, and single-Hub boundary remain the defined security controls.
