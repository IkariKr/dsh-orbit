## 5. Scope Boundary & Known Limitations

### Scope Boundary
- **Reverse-Connected Nodes**: **Explicitly NOT in v0.4.** Reverse connection, NAT traversal, and pairing are deferred to v0.5.
- **No Fleet Execution / Terminal Streaming**: Terminal PTY and agents run capabilities remain deferred.
- **Version Closure**: Official package version frozen at `0.4.0-rc.1`.

### Known Limitations
1. **Process-Local Nonce Replay Cache**: RouteIngress nonce cache is in-memory per-process. Security across process restarts is bounded by request signature validation and the 30-second timestamp skew window.
2. **No Silent Failover**: An outage on an active node fails closed immediately; operator traffic is never silently redirected to an alternate node.
3. **Routing Prerequisites**: Deploying v0.4 requires wildcard DNS, wildcard TLS termination at an outer authenticated reverse proxy, and preservation of incoming `Host` headers.
