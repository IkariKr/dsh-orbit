## 5. Scope and limitations

- Reverse-connected nodes, NAT traversal, reverse tunnels, fleet execution, `terminal.pty`, and `agents.run` are not part of v0.4 and remain outside this release candidate.
- RouteIngress nonce replay cache is process-local. Restart resets the cache; the bounded security boundary is signed proof, the 30-second timestamp skew window, and the single-Hub assumption.
- Node failure fails closed; there is no silent failover.
- Routing requires wildcard DNS, wildcard TLS, an authenticated outer gateway, and preserved `Host` headers.
