### NSS certutil environment note (outside the repository)

The machine provides Mozilla NSS `certutil` (MSYS2 mingw-w64 build of NSS
3.129 with its NSPR/SQLite/Zlib runtime DLLs) under
`C:\Users\41382\tools\nss\mingw64\bin\`, exposed to the harness through
`DSH_ORBIT_NSS_CERTUTIL=C:\Users\41382\tools\nss\nss-certutil.cmd`. That
launcher (a) passes every invocation through unchanged to the real NSS
`certutil.exe` beside it, and (b) answers the harness capability probe
(`certutil -H`) by running the same real binary's `--syntax` summary,
because recent NSS builds answer `-H` with a detailed help format that does
not carry the `certutil -A` / `certutil -N` usage literals the probe checks
for. All database operations (`-N`, `-A`, `-L`) are executed by the genuine
NSS binary; the Windows built-in `certutil.exe` was verified to be rejected
by the probe (negative test executed during environment preparation).
