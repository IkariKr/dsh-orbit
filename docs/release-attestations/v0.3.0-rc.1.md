## Required release evidence

### Fresh and migration installs

The final evidence records a fresh empty Registry install and real file-backed
v1 → v3, v2 → v3, and v3 validated no-op reopen. For each version it records
schema shape, integrity/FK result, row/state preservation, and idempotent reopen.

### Backup and restore

The Registry backup method is `sqlite-vacuum-into`. The evidence records source
and standalone image inspection, WAL/SHM handling, mutation visibility before
restore, atomic staged restore after writer quiescence, restored state digest,
and cleanup. Orbit creates the temporary backup path exclusively at POSIX
`0600` before SQLite writes and retains final chmod enforcement. The generic DSH
snapshot contract remains separate.

### Failure drills

The final record includes unsupported-future, malformed, plain-corrupt,
valid-header business-page-corrupt, and existing-FK-violation rejection. Each
failure must occur before Hub `registry listening`, preserve source bytes, and
avoid rebuild or overwrite.

### Restart and health

The final record includes real Hub A → Hub B restart on the same persistent DB,
Node identity/key/report/audit/session preservation, killed-process rotation
recovery without a third key, killed-process reenrollment exact replay with the
same node ID, and long-downtime `lost + contact-lost` behavior. It records that
report upload cannot heal contact and authenticated heartbeat restores fresh.

### Fresh mounted live smoke

The fresh mounted run must use the existing trusted Caddy/Hub/private-machine
 topology and record:

- live run ID and exact candidate commit;
- Hub, DSH A/B, and Caddy image IDs/digests where available;
- TLS validation enabled, CA/leaf fingerprints and SANs;
- real browser session/bootstrap checkpoints;
- sanitized Node A/B IDs, report outcomes, capabilities, heartbeat/contact;
- lifecycle transitions, restart, isolation, deletion, reenrollment, and cleanup.

The `longLivedTransport`, `terminalFence`, and `terminalPtty` results remain
exactly as actually observed; `not_run` is not converted to pass.

## Known limitations

- POSIX permission-bit assertions are skipped on Windows; platform ACLs remain
the Windows control.
- GNU tar behavior for Windows paths is environment-skipped.
- Local Docker image repository digests may be unavailable; record immutable
image IDs when that is the environment's available identity.
- `longLivedTransport` and `terminalPtty` remain `not_run` unless a fresh run
observes them; the legacy third-party terminal fence remains freeze-only.
- The third-party plugin boundary is unchanged: Orbit supports DSH core and
maintains no third-party plugin ecosystem compatibility.
- A final release tag, published release, and production promotion are outside
this candidate and require final review after Stage 8.
