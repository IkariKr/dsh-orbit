### Details of P3 Findings (Advisories for Stage 4 Hardening)

1. **P3-01: Default EventEmitter MaxListeners in `PairingCodeEngine`**
   - **File**: `src/registry/pairing-code.mjs`
   - **Observation**: `PairingCodeEngine` inherits default Node.js `EventEmitter` settings with 10 maximum listeners. If more than 10 operator client tabs open SSE streams at `GET /hub/pairing/events` concurrently, Node.js emits a `MaxListenersExceededWarning` to stderr.
   - **Recommendation**: Set `this.setMaxListeners(100)` or higher in `PairingCodeEngine` constructor during Stage 4 resilience hardening.

2. **P3-02: Unbounded Inactive Entries in `ipAttempts` Map**
   - **File**: `src/registry/pairing-code.mjs`
   - **Observation**: In `checkIpLockout`, expired lockouts are cleaned up when `stat.lockedUntil <= nowMs`. However, if an IP address fails between 1 and 4 times and never calls again, `stat.lockedUntil` remains 0, leaving the entry in memory indefinitely. Under large-scale scanner activity, this map could slowly accumulate dead records.
   - **Recommendation**: Introduce a sliding window expiry or periodic cleanup routine (similar to `SlidingWindowLimiter` in `server.mjs`) during Stage 4 rate-limiting hardening.

3. **P3-03: Scheme Validation Defense-in-Depth for Pairing URL Generation**
   - **File**: `src/registry/server.mjs`
   - **Observation**: `POST /hub/pairing/generate-code` generates `hubBaseUrl` via `${trustedExternalScheme}://${request.headers.host}`. If an operator misconfigures Orbit without setting `trustedExternalScheme: "https"`, it defaults to `"http"`.
   - **Recommendation**: Add a defense-in-depth assertion in `generateCode` or `server.mjs` to fail closed or emit a high-priority warning if pairing codes are generated over unencrypted HTTP.

## 3. Strict Invariant Verification

1. **Release Tag and Promotion Prohibition**:
   - `git tag` was inspected. No unauthorized tags (`v0.8.0-rc.1`, `v0.9.0-rc.1`) exist. No promotion scripts or DNS modifications were executed.
   - Status: **COMPLIANT**

2. **Strict Identity Boundary (Operator Session vs. Machine Node)**:
   - Verification of pairing codes in `handlePairingVerify()` invokes `registry.bootstrapSession({ principal: operatorPrincipal })` and issues an operator cookie (`dsh-orbit-hub-session`).
   - The verified client is stored exclusively in `browser_sessions`. It receives no Ed25519 machine credentials, no `nodeId`, and no machine execution privileges. Machine nodes continue to be managed strictly via RFC-0001/RFC-0012 protocols.
   - Status: **COMPLIANT**

3. **No Virtual Loopback Spoofing**:
   - `handlePairingVerify()` consumes `request.socket.remoteAddress` directly without spoofing or rewriting to `127.0.0.1`.
   - `checkOriginAndFetchSite()` enforces Origin protocol and host matching against `trustedExternalScheme` and explicitly denies `cross-site` requests (403 `cross-site-denied`).
   - Status: **COMPLIANT**

4. **Transport Security (Verified TLS Invariant)**:
   - Verified that pairing URLs are constructed as `https://<host>/auth?token=<code>` under configured TLS schemes.
   - Server endpoints validate Origin against `${trustedExternalScheme}:`.
   - Status: **COMPLIANT**

5. **Ephemeral Single-Use Disposable Codes**:
   - `PairingCodeEngine` uses `crypto.randomInt(100_000, 1_000_000)` ensuring cryptographically random 6-digit integers.
   - TTL is set to 300 seconds (5 minutes) with timer unreferencing.
   - Single-use destruction is executed immediately upon verification attempt (`this.codes.delete()` and `this.tokens.delete()`), preventing replay attacks.
   - Status: **COMPLIANT**

6. **Zero Leaks**:
   - `POST /hub/pairing/verify` returns only `{ ok: true, principal, csrfToken, expiresAt }`.
   - `GET /hub/pairing/status` returns only aggregated counts (`activeCodes`), never plaintext tokens.
   - `GET /hub/pairing/events` emits only metadata (`device-connected`, `operatorPrincipal`, `clientIp`, `timestamp`).
   - Node tables (`nodes`, `historical_nodes`, `node_reports`) are completely untouched. Plaintext pairing secrets are never stored in node state or exposed on public surfaces.
   - Status: **COMPLIANT**
