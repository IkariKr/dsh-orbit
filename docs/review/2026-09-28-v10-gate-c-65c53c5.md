## Findings and disposition (converged before the re-freeze review)

- **[P1] M1's success criterion was unsatisfiable under the recorded edge
  strategy** — the mounted criterion demanded the selector UI on the phone,
  but the recorded exemption covered only `GET /auth` and
  `POST /hub/pairing/verify`, leaving `/`, the selector assets, and
  `/hub/session` behind the edge gate; widening the exemption post-freeze
  would have violated the freeze rule. **Adjudicated (narrow option)**: the
  exemption set is final and minimal — exactly the two self-defending pairing
  paths; **everything else keeps the gate** (including `/`, selector assets,
  `/hub/session`, `/hub/selector/nodes`). M1's criterion is revised to the
  honest form: credential-free landing + verification + operator session
  issuance on the phone, then selector reachability **with the operator's
  existing edge credential**, demonstrating the pairing-issued session is the
  session the selector consumes. Widening to a publicly reachable selector
  surface was evaluated and **rejected** (the apex session bootstrap is
  gateway-open; that widening is a future, separately authorized
  security-posture decision). Recorded in RFC §2/§4/D7-M1 and the
  authorization JSON `must` entry.
- **[P2] The required edge deployment change had no in-repo artifact.**
  **Fixed**: `docker-registry/Caddyfile.example` now carries the exact
  exemption snippet (two `handle path` blocks before `basic_auth`, with the
  do-not-widen rationale inline) and the SOP Stage 4 deployment runbook spells
  out the steps (`caddy validate`, restart, hub env, closure recording).
- **[P3] `DSH_ORBIT_HUB_QR_PAIRING_BASE_URL` missing from
  `docs/configuration-reference.md`** (and the machine-pairing env, per the
  same gap). **Fixed**: both envs documented in the reference table.
- **[P3] The 13/13 automated report is shape-canonical with hardcoded PASS**
  (v0.9-identical pattern). **Accepted as precedent**; the SOP now states
  explicitly that the full suite run is the real pass evidence and fixes the
  report's path (`docs/review/v10-m17-automated-qualification-<sha>.json`).
- **[P3] The Gate 1 convergence commit's product bytes (`1ca5dc6`) had no
  independent gate header.** **Addressed**: this Gate C review audited the
  final candidate bytes as a whole (full diff read + mechanical coverage
  mapping + live probes), and the freeze record will name `65c53c5`-lineage
  bytes as reviewed; future waves must include convergence-commit bytes in
