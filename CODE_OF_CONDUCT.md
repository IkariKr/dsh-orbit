# Code of Conduct

DSH Orbit welcomes technical discussion, bug reports, documentation improvements, and code contributions from people with different backgrounds and levels of experience.

Participants are expected to:

- discuss ideas and code on their merits;
- give specific, actionable feedback;
- avoid harassment, personal attacks, and discriminatory language;
- respect security-reporting boundaries and user privacy;
- assume good intent while remaining precise about technical risk.

Maintainers may remove content or restrict participation when behavior repeatedly disrupts the project or puts users at risk.
